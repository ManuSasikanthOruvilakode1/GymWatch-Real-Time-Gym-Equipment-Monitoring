# Videos (not included)

Recordings or test clips for the live monitor go here (`.mov`, `.mp4`, ...). The clips used in
the README results are private and not in this repository.

Point a camera at a file in `configs/default.yaml` (`monitor.cameras[].source`). Files play back
in real time, so a recording behaves like a live camera. Hand labels for evaluation go in
`configs/video_labels.yaml`.
